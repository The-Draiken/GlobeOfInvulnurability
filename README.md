# An Actual Invulnurable Globe
Never Liked DnD Globe of Invulnerability. Grew up reading Comics where the Word Invulnerable actually means Invulnerable like Superman, The Hulk , Sentry , Blue Marvel , etc.

So what this Mod does is it Makes the Globe Of Invulnerability actually an Indestructible Forefield, not a status effect field.
It is immune to Physical damage and Resistant to All Magical Damage.

**Compatibility with Skynet**
Skynet AI actual Recognises how the Globe Functions from this Mod and will adapt to it, attempiting to counter it appropriatly.
